What it actually does

Nine data types, five triggers, and a domain rule you can explain in one sentence.

1

Preview first

Every cleanup starts with a summary: how many sites matched, how many history entries and cookies will go, and which retention window applies.

Targeted by default

Only the domains on your clean list are touched. Everything else is never included, so a free user has no way to lose data by accident.

What VKT CleanMate cannot do

  • It cannot clear DNS caches, router logs, ISP records or server-side logs.
  • It cannot restore deleted history — browsers provide no API to write history back.
  • It cannot clean other browsers’ data, other profiles, or a synced copy on another device.
  • “On browser close” is best-effort: if the browser exits mid-task, cleanup finishes a few seconds after the next start.
  • It cannot limit history, downloads, form data or passwords to a single site — the browser doesn’t expose that, and the UI says so.
  • It is not an anonymity or anti-surveillance tool. It is a self-service privacy tool for your own browser.
