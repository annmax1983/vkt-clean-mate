## なぜ VKT CleanMate なのか

多くのクリーナーは「全部消す」ボタンが一つだけです。だから怖くてオンにできない。一回押せば、すべてのサイトのログインが消えます。さらに悪いことに、押す前には 3 サイト分なのか 3000 サイト分なのかも分かりません。

VKT CleanMate は「決める」と「実行する」を分けました。

| 他のクリーナーのやり方 | 代償 |
|---|---|
| 一つのスイッチですべて消える | 一度の誤操作で、ログインも Cookie もダウンロード履歴も消える |
| 数字の書かれていない確認ダイアログ | 実行する前に、何件動くのか分からない |
| サイト規則が正規表現の入力欄の奥にある | 誰も書かないので、「安全なモード」は実際には使われない |

| VKT CleanMate のやり方 | 結果 |
|---|---|
| **実行のたびにプレビューシート** | ブラウザから取得した実数：対象サイト、履歴の件数、Cookie の数、有効なデータ種別、保持期間 |
| **無料版は全消去を実行できない** | 無料ユーザーに誤削除の道がない — 警告ではなく設計 |
| **逆向きの二つのリスト** | クリーンリスト（「ここだけ」、無料）と保護リスト（「ここは絶対」、有料） |
| **できないことを明記する** | インターフェースにもこの README にも書く。レビュアーに発見させない |

一行で言えば：**削除する前に何が消えるかを見せ、削除したあとに時間の行き先を教える。**

## 機能一覧

### 🆓 無料機能

| 機能 | 内容 |
|---|---|
| 削除前のプレビュー | 対象サイト、履歴の件数、Cookie の数、データ種別、保持期間を実行前に一覧表示 |
| 指定モード | クリーンリストのドメインだけを削除。件数無制限 |
| 九つのデータ種別 | 履歴、キャッシュ、Cookie、ダウンロード履歴、フォームデータ、ローカルストレージ、IndexedDB、Service Worker、保存されたパスワード。それぞれ独立したスイッチ |
| 保持期間 | 直近 1 時間 / 3 日 / 7 日 / 30 日、またはすべて削除 |
| 五つのトリガー | ブラウザ起動時、終了時、N 分ごと、毎日決まった時刻、N 分間アイドル後 |
| トリガーごとの範囲 | 例：数時間ごとは履歴＋キャッシュだけ、ブラウザ終了時は Cookie 込みで深く削除 |
| ショートカット | `Alt+Shift+C` 今すぐ削除 · `Alt+Shift+X` 削除してすべてのタブとウィンドウを閉じる |
| 延期 | 次の自動実行を 1 時間後ろへ |
| 完了通知 | 実行のたびに結果の要約 |
| 六つの言語 | English、简体中文、日本語、Deutsch、Español、Français |

### ⭐ Pro 機能（ライセンスが必要）

| 機能 | 内容 |
|---|---|
| 全消去モード | 保護リスト以外をすべて削除 |
| 保護リスト | 絶対に触らないドメイン。両方のリストに載った場合は保護が優先 |
| フォーカス足跡 | ドメインごとの実際のフォーカス時間、24 時間分布、ランキング、「掃除する価値あり」の提案 |
| CSV 書き出し | 足跡データを 1 行 1 ドメインの CSV に |

ライセンス一本で二つのブラウザをカバーします。期限が切れても無料機能はそのまま動きます。

## できること・できないこと

### ✅ できること

- 履歴、キャッシュ、Cookie、ダウンロード履歴、フォームデータ、ローカルストレージ、IndexedDB、Service Worker、パスワードを任意の組み合わせで削除する。
- 削除対象を自分で書いたドメインに限定する。ドメインとそのサブドメインに一致し、正規表現は不要。
- 全消去モードで、保護したドメインを飛ばす。
- スケジュールで自動実行し、トリガーごとに別のデータ範囲を持たせる。
- 実行のたびに、何を消したかを正確に報告する。

### ❌ できないこと

- DNS キャッシュ、ルーターのログ、プロバイダの記録、サーバー側のログは消せない。端末の外にあるもの。
- 削除した履歴は復元できない。Chromium はどの拡張機能にも履歴の書き込み API を提供していない。
- 他のブラウザのデータ、別のプロファイル、他の端末に同期されたコピーは消せない。
- 履歴、ダウンロード、フォームデータ、パスワードを単一サイトに限定できない。ブラウザが公開していない。この四種類は全消去モードでのみ絞り込まれ、その旨はチェックボックスの隣に書いてある。
- 「ブラウザ終了時」の実行を保証できない。ベストエフォートであり、クラッシュ・強制再起動・停電でその一回は失われうる。
- 保存されなかったものは消せない。シークレットウィンドウで読んだだけのページは、そもそも痕跡を残さない。
- VPN の代わりにはならず、ネットワーク側の監視にも対抗できない。自分の端末の、自分のブラウザのためのセルフサービスツール。

## 使い方

### 初回

ポップアップを開いて「今すぐクリーニング」を押します。既定は指定モードでクリーンリストが空なので、まだ何も起きません。それが正しい動作です。まず `Lists` タブでドメインを追加してください。

### クリーンリストの埋め方

- ポップアップ：**現在のサイトを追加** で、見ているドメインを登録。
- `Lists` タブ：`example.com` と入力して Add。サブドメインは自動でカバーされ、`www.` は取り除かれます。
- 足跡ページ（Pro）：「掃除する価値あり」の提案とランキングの各行に、そのドメインを追加するボタンがあります。

### 自動実行の設定

`Cleaning` タブの五つのトリガーには、それぞれ独立したスイッチがあります。その下のドロップダウンが、そのトリガーのデータ範囲を決めます。`global` は上のチェックボックスに従い、それ以外の値はその回だけプリセット（履歴＋キャッシュ、Cookie＋キャッシュ、すべて、など）に限定します。

無難な出発点：6 時間ごとに履歴＋キャッシュ、ブラウザ終了時にすべて、起動時とアイドルは必要性を確認するまでオフ。

### ショートカット

| キー | 動作 |
|---|---|
| `Alt+Shift+C` | 現在の設定で今すぐ削除 |
| `Alt+Shift+X` | 今すぐ削除し、すべてのタブとウィンドウを閉じる |

どちらも `chrome://extensions/shortcuts` で変更できます。

## 仕組み

1. トリガーが発火するか、「今すぐクリーニング」を押します。
2. バックグラウンドの Service Worker が対象ドメインを確定します。指定モードならクリーンリスト、全消去モードなら「すべてから保護リストを引いたもの」。
3. 影響を受ける件数 — サイト数、履歴、Cookie — を数え、プレビューシートを表示します。**この時点では何も削除されていません。**
4. 確認すると、選択した種別が `chrome.browsingData` で削除されます。1 バッチあたり最大 50 origin。
5. ドメイン規則は先に実際の origin へ展開されます。`browsingData` は裸のホスト名ではなく origin（`https://example.com`）を受け取り、サブドメインを自分で展開することはありません。
6. 完了後に結果を通知し、実行時刻を記録します。プレビューシートはポップアップからいつでも確認できます。

知っておく価値のある実装上の注意：`browsingData` の `origins` は、キャッシュ、Cookie、ローカルストレージ、IndexedDB、Service Worker、ファイルシステムにのみ効きます。履歴、ダウンロード、フォームデータ、パスワードはこのリストを完全に無視するため、これらを選ぶと対象はプロファイル全体になります。拡張機能はそれを隠さず、インターフェースに明記しています。

## よくある質問

**削除するとブックマークも消えますか？**
いいえ。ブックマークは `browsingData` の対象外で、拡張機能内に触れるコードはありません。

**Cookie を消すと全サイトからログアウトしますか？**
指定モードでは、リストに書いたドメインだけです。無料版が指定モードしか動かないのはそのためです。全消去は意図的に選ぶ有料の判断であり、保護リストとセットで使うものです。

**特定のサイトの履歴だけ消せますか？**
はい。任意の `history` 権限が必要で、サイト単位で履歴をプレビューまたは削除する瞬間にだけ要求されます。インストール時ではありません。

**Google アカウントに同期されたパスワードも消えますか？**
「保存されたパスワード」にチェックを入れると、ブラウザはローカルのパスワードストアを削除し、サインイン中のプロファイルではその削除が同期されることがあります。この種別が既定でオフで、インターフェース上も赤く表示されているのはそのためです。必要がなければ触らないでください。

**シークレットウィンドウでも動きますか？**
シークレットウィンドウは閉じた時点で自身のデータを破棄するので、消すものは残りません。拡張機能がシークレットウィンドウにアクセスする必要もありません。

**「ブラウザ終了時」が実行されませんでした。**
ベストエフォートです。ウィンドウ数がゼロになった時点で発火し、実行中にブラウザが終了した場合は次回起動の数秒後に完了します。クラッシュ、強制再起動、停電ではその回は失われます。

**他のブラウザや他のプロファイルも消せますか？**
いいえ。一つのプロファイル、一つのブラウザ、この端末だけです。

**なぜ保護リストが有料なのですか？**
無料版が意図的に全消去を実行できないからです。「すべて消す」はリスクの高い操作であり、安全網とセットで提供するのが筋だからです。

## プライバシー

解析なし、テレメトリなし、広告なし、アカウントなし。拡張機能はページの内容を読まず、キー入力を記録せず、プロファイルも作りません。設定は `chrome.storage.local` に保存されます。フォーカス足跡を有効にした場合も、ドメイン、時間、訪問回数、時間帯ヒストグラムを 30 日のローリング期間で保存するだけです。URL もタイトルも保存しません。拡張機能全体で唯一の通信は `api.annmax1983.com` に対するライセンス確認で、キーを貼り付けたときにだけ発生します。

**[📄 プライバシーポリシー全文](../privacy-policy.html)**

### 権限について

| 権限 | 用途 |
|---|---|
| `browsingData` | 選択したデータ種別の削除 |
| `storage` | 設定と任意の足跡データを端末内に保存 |
| `alarms` | スケジュールと、フォーカス計測用の毎分ハートビート |
| `tabs` | 現在のドメインの取得と、表示中タブへの操作 |
| `windows` | 最後のウィンドウが閉じたことの検知（「終了時」トリガーの根拠） |
| `idle` | 任意の「アイドル後」トリガー |
| `notifications` | 実行後の結果通知 |
| `history`（任意） | サイト単位で履歴をプレビュー・削除するときだけ要求 |
| `cookies`（任意） | サイト単位で Cookie を削除するときだけ要求 |
| `api.annmax1983.com` | ライセンスの有効化と検証のみ |

任意の二つがあるおかげで、インストール直後に「閲覧履歴の読み取り」という赤い警告が出ません。

```bash

npm run icons                 # icons/*.png を再生成（依存なし）
```

### フォーカス足跡について

- 既定はオフで、有料機能です。
- 既定では足跡ページを開いている間だけ収集します（長寿命ポートで維持）。ページを閉じれば停止。
- Service Worker では `setInterval` が使えません。セッションはタブ／ウィンドウのイベントで確定し、1 分ごとの alarm で補完します。
- 保存するのは `domain`、`duration`、`visits` と時間帯ヒストグラムのみ。URL もタイトルも保存しません。
- 無料ユーザーにはライセンス案内カードを表示し、ポートを開かないので何も記録されません。

## 著作権について

VKT CleanMate は独立したツールであり、Google、Microsoft、その他ブラウザベンダーとは関係ありません。Chrome と Edge は各所有者の商標です。

拡張機能はブラウザ自身の API でデータを削除します。ブラウザを改変せず、システムファイルも変更せず、自身の拡張機能フォルダの外には何もインストールしません。

## ソースコードについて

公開パッケージには可読な JavaScript が入っています。難読化はしていません。`dist/` はビルド済みの圧縮版で、このリポジトリのソースがその入力です。リモート読み込みは一切ありません。`eval` もリモートスクリプトも、パッケージ外を指す動的 import もなく、これは `manifest.json` の MV3 コンテンツセキュリティポリシーで強制されています。
